操作手冊

社群貼文健診站針對你貼上的貼文文字，依 8 個維度給出評分、說明與改善建議，最後產生一份「改善後貼文」。沒有 API 金鑰也能使用規則式引擎完成基礎健診，填入 API 金鑰則能取得更精準的語意層評分與改寫。

操作步驟

  1. 選擇「目標平台」（Facebook／Instagram／X／Threads／通用），這會影響字數建議、hashtag 數量與演算法重點的評分標準
  2. 把要健診的貼文全文（含 hashtag）貼到「貼文原文」欄位，或點選下方 5 組範例快速體驗（範例涵蓋不同品質程度，皆為虛構情境）
  3. 選填：填寫「貼文目的」與「目標受眾」，可讓「語氣與受眾契合度」這個維度評分更精準
  4. 選用：展開「AI 深度健診設定」，選擇服務商並填入你自己的 API 金鑰，取得語意層的深度評分與改寫；不填金鑰也能使用規則式引擎完成基礎健診（字數／CTA／hashtag／濫用字詞偵測等）
  5. 按「🩺 開始健診」，下方會出現總分健檢儀表、8 張維度卡片，以及一份可編輯、可複製的「改善後貼文」處方箋

8 個評量維度

  • 開頭吸引力：前幾秒能不能抓住讀者的注意力
  • 核心訊息清晰度：讀完能不能一句話講出這篇在說什麼
  • 語氣與受眾契合度：用詞語氣是否符合宣告的目的與受眾
  • CTA明確度：有沒有具體可執行的行動呼籲
  • 長度與排版易讀性：字數與分段是否符合平台的閱讀習慣
  • Hashtag使用：數量與相關性是否恰當
  • 情感共鳴／故事性：是資訊條列還是有畫面感的故事
  • 演算法友善度：有沒有過度促銷或誘導互動的訊號，可能被平台降低觸及

AI 深度健診設定（選用，需自備 API 金鑰）

「開始健診」預設會使用本機規則式引擎（字數/CTA/hashtag/濫用字詞等基礎檢查，不連網），效果陽春但完全免費。若想要更精準的語意層評分與改寫，可以自己接上語言模型：

  1. 展開「AI 深度健診設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter）；模型欄已列出幾個常用模型可直接選用，也可選「✏️ 自訂模型名稱」自行輸入其他模型 ID
  2. 填入你自己申請的 API 金鑰
  3. 按「開始健診」時，若金鑰有填就會自動改用 AI 評分與改寫；若某個維度的 AI 結果解析失敗，該維度會自動退回規則式評分，並在健診報告下方提示
API 金鑰只存在你這台電腦的瀏覽器（localStorage），使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰。

平台規則說明

  • Facebook：建議 400-600 字，語氣親切、鼓勵留言互動，hashtag 1-2 個
  • Instagram：建議 150-300 字，開頭要抓眼球，hashtag 8-15 個
  • X（Twitter）：硬性上限 280 字，簡短有力，hashtag 1-2 個
  • Threads：上限 500 字，語氣輕鬆對話感，hashtag 2-4 個
  • 通用：未指定特定平台時的中性寬鬆標準，建議 150-400 字，hashtag 3-6 個

隱私說明

  • 貼文原文、平台選擇、目的與受眾會存在瀏覽器 localStorage（草稿），關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器
  • AI API 金鑰只存在瀏覽器 localStorage，換一台電腦或清除瀏覽器資料就會不見
  • 按「開始健診」若填有 API 金鑰，貼文內容會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器

使用警語

請注意：
  • 本工具的規則式引擎完全不連網；只有填入 API 金鑰並按下「開始健診」時才會對外連線
  • 請勿在任何欄位輸入真實個資、公司機密、他人受著作權保護的內容，或不希望被 AI 服務留存的敏感資訊
  • 健診結果（含分數、說明與改善版貼文）皆為參考建議，不保證絕對正確或適用於所有情境，發布前請自行判斷
  • 使用 AI 健診功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用
